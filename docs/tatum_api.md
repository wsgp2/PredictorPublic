# Интеграция с Tatum API

## Обзор
Данная документация описывает интеграцию с Tatum API для получения данных о ценах криптовалют. Мы используем API v3, так как он предоставляет более стабильный доступ к данным о ценах по сравнению с v4.

## Конфигурация API
### API Ключи
- **Бесплатный план**: 100K кредитов в месяц
- **Ограничение запросов**: 3 запроса в секунду (RPS)
- **Количество API ключей**: 2 (mainnet и testnet)

### Файл конфигурации
Файл: `config/api_keys.json`
```json
{
    "tatum": {
        "mainnet": "your-mainnet-api-key",
        "testnet": "your-testnet-api-key"
    }
}
```

## Коллектор данных
### Основной класс
`TatumDataCollector` (`data_collectors/tatum_v4_collector.py`) - основной класс для работы с API.

### Инициализация
```python
collector = TatumDataCollector(api_key=None)  # Если api_key не указан, используется тестовый ключ
```

### Основные методы
#### Получение текущей цены
```python
price = collector.get_bitcoin_price(base_pair="USD")
```
Возвращает словарь с информацией о цене:
```json
{
    "value": "97806.95106600",
    "basePair": "USD",
    "timestamp": 1735987406358,
    "source": "CoinGecko",
    "id": "BTC"
}
```

#### Получение исторических цен
```python
history = collector.get_historical_prices(days=7, base_pair="USD")
```
Возвращает DataFrame с колонками:
- `timestamp`: время измерения (индекс)
- `price`: цена в указанной валюте
- `source`: источник данных

### Обработка ошибок
Коллектор автоматически обрабатывает:
- Ошибки авторизации (401)
- Ограничения доступа (403)
- Превышение лимита запросов (429)
- Сетевые ошибки

### Rate Limiting
- Автоматическое соблюдение ограничения 3 RPS
- Задержка между запросами: 0.34 секунды
- Автоматическая обработка ошибки 429 с повторным запросом

## Примеры использования
### Базовый пример
```python
from data_collectors.tatum_v4_collector import TatumDataCollector

# Создаем коллектор
collector = TatumDataCollector()

# Получаем текущую цену
price = collector.get_bitcoin_price()
print(f"Текущая цена BTC: ${price['value']}")

# Получаем исторические данные
history = collector.get_historical_prices(days=7)
print(f"История цен:\n{history}")
```

### Расширенный пример
См. файл `test_tatum_price.py` для полного примера использования с логированием.

## Ограничения и особенности
1. **Бесплатный план**:
   - 100K кредитов в месяц
   - 3 запроса в секунду
   - Ограниченный доступ к некоторым эндпоинтам

2. **API v3 vs v4**:
   - Используем v3 для цен, так как эти эндпоинты более стабильны
   - v4 находится в разработке и может иметь ограничения

3. **Данные**:
   - Цены обновляются в реальном времени
   - Источник данных: CoinGecko
   - Поддерживаются различные базовые валюты (USD, EUR и др.)
