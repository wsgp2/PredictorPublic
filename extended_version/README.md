# Bitcoin Price Predictor - Extended Version

Система для сбора и анализа данных для предсказания цены Bitcoin, использующая различные источники данных и метрики. Все данные хранятся в PostgreSQL базе данных для обеспечения надежности и удобства анализа.

## Основные компоненты

1. **Коллекторы данных**
   - BlockchainDataCollector (v2) - данные блокчейна
   - YahooFinanceCollector - данные акций и индексов
   - SentimentDataCollector - индекс страха и жадности
   - LunarCrushCollector - социальные метрики
   - CoinArkCollector - данные деривативов
   - GoogleTrendsCollector - поисковые тренды

2. **База данных**
   - PostgreSQL для хранения всех данных
   - Оптимизированные индексы
   - Автоматическое заполнение пропусков

3. **Система анализа**
   - Предварительная обработка данных
   - Корреляционный анализ
   - Подготовка для ML моделей

## Источники данных

1. **Blockchain.info API**
   - Рыночные метрики
   - Майнинг метрики
   - Сетевые метрики
   - Обновление каждые 8 часов

2. **Yahoo Finance**
   - Криптокомпании (MSTR, COIN, MARA, RIOT)
   - Индексы (SPY, QQQ, GLD, UUP)
   - Ежедневное обновление

3. **Alternative.me**
   - Индекс страха и жадности
   - Анализ настроений
   - Ежедневное обновление

4. **LunarCrush**
   - Социальные метрики
   - Рыночные метрики
   - Новостные метрики
   - Метрики влиятельных лиц
   - Ежедневное обновление

5. **CoinArk**
   - Фьючерсы
   - Деривативы
   - Long/Short позиции
   - Обновление каждый час

6. **Google Trends**
   - Поисковые тренды
   - Региональные данные
   - Ежедневное обновление

## Установка и настройка

1. **Требования**
   ```bash
   python >= 3.8
   PostgreSQL >= 13
   ```

2. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройка базы данных**
   ```bash
   # Создание базы данных
   createdb bitcoin_predictor

   # Применение миграций
   python migrate.py
   ```

4. **Настройка переменных окружения**
   ```bash
   cp .env.example .env
   # Заполните .env файл необходимыми API ключами
   ```

## Использование

1. **Сбор исторических данных**
   ```bash
   python historical_data_collector.py
   ```

2. **Запуск отдельных коллекторов**
   ```bash
   python blockchain_data_collector_v2.py
   python sentiment_data_collector.py
   python lunarcrush_collector.py
   ```

3. **Анализ данных**
   ```bash
   python analysis/correlation_analysis.py
   python analysis/feature_engineering.py
   ```
