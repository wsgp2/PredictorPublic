# Сбор данных для предсказания цены Bitcoin

## Текущая структура проекта

### Основные файлы и директории

```
extended_version/
├── blockchain_data_collector.py    # Сбор данных с Blockchain.com API
├── historical_data_collector.py    # Управление историческими данными
├── config/                        # Конфигурационные файлы
│   └── config.py                 # Конфигурация API
├── data/                         # Директория для данных
│   └── historical/              # Исторические данные в CSV
├── docs/                        # Документация проекта
└── requirements.txt            # Зависимости проекта
```

## Интеграция данных

### 1. Предобработка
- Объединение всех метрик по временной метке
- Обработка пропущенных значений
- Нормализация данных
- Создание скользящих средних

### 2. Анализ
- Корреляционный анализ метрик
- Выявление важных признаков
- Визуализация зависимостей
- Поиск паттернов

### 3. Подготовка для модели
- Разделение на тренировочную/тестовую выборки
- Создание временных рядов
- Определение окна предсказания
- Валидация данных

## Примечания

- Все конфигурации хранятся в `config/config.py`
- Логи сбора данных сохраняются с информацией о каждой метрике
- Документация API находится в `Документация blockchain.com/`
- Исторические данные обновляются автоматически при каждом запуске
- В среднем каждая метрика содержит ~1500 записей
- Некоторые метрики имеют более 2000 записей
