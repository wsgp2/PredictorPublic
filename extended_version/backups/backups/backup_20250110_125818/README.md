# Bitcoin Price Predictor

Система для сбора и анализа данных для предсказания цены Bitcoin, использующая различные источники данных и метрики.

## Архитектура проекта

### Источники данных

1. **CoinArk API**
   - K-line данные (OHLCV)
   - Данные ордербука
   - Long/Short позиции
   - Данные о ликвидациях
   - Ставки финансирования
   - Открытый интерес

2. **CoinGecko API**
   - Исторические цены
   - Рыночная капитализация
   - Объемы торгов
   - Данные о листингах

3. **Yahoo Finance**
   - Данные о криптокомпаниях (MSTR, COIN, MARA, RIOT)
   - Индексы (SPY, QQQ, GLD, UUP)

4. **Blockchain.com**
   - Активные адреса
   - Количество транзакций
   - Размер мемпула
   - Сложность майнинга
   - Комиссии
   - UTXO статистика

5. **LunarCrush**
   - Социальные метрики
   - Настроения рынка

6. **FRED (Federal Reserve Economic Data)**
   - Макроэкономические показатели

## Собираемые данные и ограничения

### CoinArk API
- K-line данные:
  - 1h: ~6 месяцев (4492 записи)
  - 4h: ~14 месяцев (2496 записей)
  - 1d: ~16.5 месяцев (500 записей)
- Ограничение: 500 записей за запрос
- Требуется API-ключ (текущий уровень: базовый)

### Технические индикаторы
- RSI (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)
- Bollinger Bands
- ATR (Average True Range)
- Stochastic Oscillator
- OBV (On Balance Volume)
- Moving Averages (SMA, EMA)

## Особенности реализации

### Умное кэширование данных
- Каждый коллектор сохраняет timestamp последнего обновления
- При новом запуске собираются только недостающие данные
- Данные сохраняются в CSV формате с временными метками

### Обработка ошибок
- Автоматические повторные попытки при сбоях API
- Логирование всех ошибок и предупреждений
- Валидация полученных данных

### Многопоточность
- Параллельный сбор данных из разных источников
- Оптимизация использования API-лимитов
- Контроль нагрузки на API

## Установка и использование

1. Клонируйте репозиторий:
```bash
git clone [URL репозитория]
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл .env и добавьте API ключи:
```env
COINARK_API_KEY=your_api_key
COINGECKO_API_KEY=your_api_key
LUNARCRUSH_API_KEY=your_api_key
```

4. Запустите сбор данных:
```bash
python collectors/coinark_collector.py
```
