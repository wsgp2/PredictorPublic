# Журнал изменений

## [1.4.1] - 2025-01-14

### Добавлено
- Расширенный анализ корреляций между всеми метриками
- Группировка корреляций по источникам данных
- Топ-10 положительных и отрицательных корреляций

### Изменено
- Улучшен historical_data_collector для работы со всеми метриками
- Оптимизирована обработка пропусков в данных
- Расширено логирование результатов анализа

### Исправлено
- Исправлена обработка данных из разных источников
- Улучшена обработка ошибок при анализе

## [1.4.0] - 2025-01-14

### Добавлено
- Полная миграция на PostgreSQL для всех коллекторов данных
- Улучшенное заполнение пропусков в блокчейн данных
- Оптимизированный сбор данных с более высокой частотой

### Изменено
- Все коллекторы теперь сохраняют данные в PostgreSQL вместо CSV
- Архивированы все CSV файлы для сохранения истории
- Обновлен исторический коллектор для работы только с базой данных
- Улучшена обработка пропусков в блокчейн данных
- Уменьшено окно усреднения для более точных данных

### Исправлено
- Исправлены URL и параметры API blockchain.info
- Улучшена обработка ошибок при сборе данных
- Оптимизирована частота обновления данных

### Технические улучшения
- Стандартизация интерфейсов для работы с базой данных
- Улучшенное логирование и мониторинг сбора данных
- Оптимизация запросов к базе данных

## [1.3.0] - 2025-01-12

### Планируемые изменения
- Добавление Google Trends коллектора для отслеживания поисковых запросов
- Интеграция новостного API (CryptoCompare/CryptoPanic)
- Расширение использования данных CoinArk (балансы на биржах, спреды)

### Технические улучшения
- Добавление тестов для новых коллекторов
- Оптимизация структуры хранения данных
- Улучшение документации

### Архитектурные изменения
- Внедрение модульного тестирования для коллекторов
- Стандартизация интерфейсов коллекторов
- Улучшение обработки ошибок и логирования

## [1.2.0] - 2025-01-12

### Добавлено
- Добавлена проверка дублирования данных между коллекторами
- Улучшена документация архитектуры системы
- Добавлено тестирование коллекторов данных

### Изменено
- Оптимизирована структура сохранения данных в SQL
- Обновлены зависимости проекта

### Исправлено
- Исправлены проблемы с дублированием данных
- Улучшена обработка ошибок при сборе данных

## [1.2.0] - 2025-01-07

### Добавлено
- Сбор данных о настроениях рынка (Индекс страха и жадности)
- Автоматическое создание резервных копий
- Подробная документация архитектуры проекта

### Изменено

- Оптимизирована система логирования
- Обновлены зависимости проекта

### Исправлено
- Обработка ошибок при недоступности API
- Заполнение пропущенных данных
- Форматирование временных меток

## [1.1.0] - 2025-01-06

### Добавлено
- Автоматическое обновление данных с Blockchain.com
- Интеграция с Yahoo Finance для сбора рыночных данных

### Исправлено
- Исправлена проблема с дублированием данных при обновлении
- Исправлена обработка недоступных метрик (volume_usd, mining_revenue_percentage)

## [1.0.0] - 2024-12-31
