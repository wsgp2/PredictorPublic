# Bitcoin Price Predictor

Система для сбора и анализа данных для предсказания цены Bitcoin, использующая различные источники данных и метрики.

## Собираемые данные

### 1. Ончейн-метрики (Blockchain.com)
- Активные адреса (Active Addresses)
- Количество транзакций
- Размер мемпула
- Сложность майнинга
- Комиссии за транзакции
- UTXO (Unspent Transaction Output)
- Средний размер блока
- Время подтверждения транзакций

### 2. Рыночные данные
- Цена Bitcoin
- Рыночная капитализация
- Объем торгов
- Корреляции с:
  - Криптокомпании (MSTR, COIN, MARA, RIOT)
  - Индексы (SPY, QQQ, GLD, UUP)

### 3. Данные о настроениях рынка
- Индекс страха и жадности (Fear & Greed Index)

## Структура проекта

```
extended_version/
├── data/                         # Директория с данными
│   ├── blockchain/              # Данные блокчейна
│   ├── market_data/            # Рыночные данные
│   └── sentiment/              # Данные о настроениях
├── config/                      # Конфигурационные файлы
├── docs/                        # Документация
├── blockchain_data_collector.py # Сборщик блокчейн-данных
├── historical_data_collector.py # Основной сборщик данных
├── yahoo_finance_collector.py   # Сборщик данных Yahoo Finance
├── sentiment_data_collector.py  # Сборщик данных о настроениях
└── requirements.txt            # Зависимости проекта
```

## Установка

1. Клонируйте репозиторий:
```bash
git clone [URL репозитория]
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

### Сбор данных

Запустите сборщик данных:
```bash
python historical_data_collector.py
```

Это автоматически:
1. Соберет все метрики с Blockchain.com
2. Обновит исторические данные о цене
3. Получит данные о корреляциях с рынком
4. Обновит индекс страха и жадности

### Бэкап данных

Для создания резервной копии:
```bash
./backup.sh
```

## Особенности

- Умное обновление данных (только новые записи)
- Автоматическая валидация данных
- Обработка ошибок и пропущенных значений
- Логирование всех операций
