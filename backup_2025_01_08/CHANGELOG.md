## [2.4.0] - 2025-01-02
### Текущая структура проекта
- `model/`
  - `short_term.py` - Модель для краткосрочных предсказаний (1-7 дней)
  - `medium_term.py` - Модель для среднесрочных предсказаний (7-30 дней)
  - `trend_model.py` - Модель для анализа трендов
- `data/` - Директория для хранения исторических данных
- `logs/` - Директория для хранения логов
- `cache/` - Директория для кэширования данных API
- `tests/` - Директория с тестами
  - `test_sentiment.py` - Тесты анализа настроений
  - `test_scaling.py` - Тесты масштабирования данных
  - `test_visualization.py` - Тесты визуализации

## [2.3.0] - 2025-01-02
### Добавлено
- Класс ETFDataCollector для сбора данных о Bitcoin ETF
- Класс InstitutionalMetricsCollector для анализа фьючерсов CME
- Класс WhaleAnalyzer для анализа активности крупных холдеров
- Новые метрики для анализа институционального интереса:
  - Объем торгов ETF
  - Средневзвешенная цена ETF
  - Общие активы под управлением ETF
  - Средняя дневная доходность ETF
  - Количество активных ETF
  - Объем торгов на CME
  - Премия/дисконт фьючерсов
  - Градиент базиса
  - Индекс институциональной активности
  - Индикатор структуры рынка
- Метрики для анализа крупных холдеров:
  - Количество адресов с крупными балансами
  - Общий баланс крупных холдеров
  - Объем и количество крупных транзакций
  - Индекс доминирования китов
  - Индекс активности китов
- Расширенный анализ настроений из социальных сетей:
  - Интеграция с Reddit API для анализа постов и комментариев
  - Интеграция с Twitter API для анализа твитов
  - Анализ настроений текста с использованием TextBlob
  - Агрегация настроений по дням с учетом активности пользователей
  - Расчет общих метрик настроений и расхождений между источниками
