# История изменений

## [2.2.0] - 2025-01-02

### Добавлено
- Проверка размерности входных данных в функции predict_future
- Расширенный набор технических индикаторов (RSI, MACD, OBV)
- Улучшенная нормализация данных для предсказания будущих цен

### Изменено
- Оптимизирована функция predict_future для корректной обработки многомерных данных
- Улучшен процесс подготовки данных для предсказания будущих цен
- Обновлен формат вывода предсказаний с форматированием цен

### Исправлено
- Исправлена проблема с размерностью входных данных при предсказании
- Улучшена обработка последних данных для более точных предсказаний

## [2.1.0] - 2025-01-02

### Улучшено
- Обновлена функция визуализации результатов для более точного отображения предсказаний
- Добавлено автоматическое сохранение графиков в файлы prediction_results.png и training_history.png
- Улучшены подписи и форматирование графиков
- Оптимизировано использование памяти при создании графиков

## [2.0.0] - 2025-01-02

### Добавлено
- Функционал сохранения модели в директорию `model/`
- Индекс страха и жадности как дополнительный параметр для предсказания
- Автоматическая загрузка актуальных данных через API

### Изменено
- Упрощена архитектура LSTM модели для улучшения стабильности
- Обновлены зависимости проекта до последних версий
- Улучшена визуализация результатов

### Удалено
- Технические индикаторы (RSI, Bollinger Bands, MACD, Momentum)
- Избыточные слои нейронной сети (Dropout, BatchNormalization)

## [1.0.0] - Первоначальная версия

### Добавлено
- Базовая LSTM модель для предсказания цены Bitcoin
- Загрузка исторических данных с Yahoo Finance
- Визуализация результатов предсказания
